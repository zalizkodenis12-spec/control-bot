# 🎯 Telegram-бот для проведення конкурсів (розіграшів)

Цей бот створений для автоматизації збору учасників конкурсу в Telegram-каналі або чаті. Увесь інтерфейс бота для учасників та автора виконано **російською мовою** відповідно до технічного завдання замовника, і вся логіка (і для учасників, і для автора конкурсу) працює в **одному спільному боті**.

---

## 🚀 1. Як запустити бота

### Крок 1. Встановлення залежностей
Відкрийте термінал у папці проєкту (`d:\Мої сайти\Тг бот`) та виконайте:
```bash
pip install -r requirements.txt
```

### Крок 2. Налаштування токена та адміністратора (`.env`)
Перевірте файл `.env` у корені проєкту:
```env
BOT_TOKEN=9100137108:AAFlgDK5427hb9SVx1E_UwR2oAfW-E04-Xk
ADMIN_ID=
ADMIN_USERNAME=wwtivan
```
* **`BOT_TOKEN`** — токен вашого бота від [@BotFather](https://t.me/BotFather). Якщо потрібно замінити токен на новий, просто вставте його сюди без пробілів та лапок.
* **`ADMIN_USERNAME`** — нікнейм (username без `@`) **єдиного адміністратора (замовника)**: за замовчуванням вже прописано **`wwtivan`** (`@wwtivan`). Коли власник `@wwtivan` вперше натискає `/start` або `/admin`, бот автоматично розпізнає його за нікнеймом і назавжди прив'язує його числовий Telegram ID у базі даних, щоб йому одразу відкривалася адмін-панель і приходили сповіщення про нових учасників!
* **`ADMIN_ID`** — (опціонально) числовий Telegram ID єдиного адміністратора. Жоден інший користувач (крім `@wwtivan` / вказаного `ADMIN_ID`) ні за яких умов не може отримати права адміністратора. Якщо неавторизований користувач напише `/admin`, бот повністю проігнорує команду і нічого не відповість.

### Крок 3. Запуск
```bash
python bot.py
```
База даних SQLite (`contest.db`) створюється автоматично при першому запуску.

## 🎉 2. Як працює бот для учасників конкурсу

1. **Перехід з посту в каналі:**
   Учасник бачить пост про конкурс у Telegram-каналі та натискає кнопку **«Участвовать»** під постом (посилання виду `https://t.me/<імя_бота>?start=contest`).
2. **Натискання Start (`/start`):**
   Бот відкривається, учасник натискає **Start** (Запустить) і отримує привітальне повідомлення російською мовою з кнопкою **«🎉 Участвовать»** (доступна як інлайн-кнопка під повідомленням, так і кнопка внизу екрана).
3. **Отримання порядкового номера:**
   * При першому натисканні **«🎉 Участвовать»** бот реєструє учасника в базі даних і присвоює йому унікальний порядковий номер за зростанням (`1, 2, 3...`):
     > ✅ Вы успешно зарегистрированы в конкурсе!
     > 🎟 Ваш порядковый номер: **№1**
   * **Захист від дублів:** Якщо той самий користувач натисне кнопку **«🎉 Участвовать»** повторно (другий, третій раз або знову перейде з каналу), бот **не створює дубль**, а нагадує його поточний номер:
     > ℹ️ Вы уже участвуете в этом конкурсе!
     > 🎟 Ваш порядковый номер: **№1**
   * Якщо конкурс вже завершений автором, нові заявки не приймаються:
     > ⛔ Конкурс уже завершён! Ожидайте начала нового конкурса.

## 👑 3. Як працює панель автора (адміністратора)

Автор конкурсу користується **тим самим ботом**, що й учасники.

### Як працює доступ до адмін-панелі (суворо тільки для `@wwtivan`):
1. У файлі `.env` вже прописано нікнейм замовника: `ADMIN_USERNAME=wwtivan` (також підтримується `ADMIN_ID=`).
2. Щойно замовник з акаунта **`@wwtivan`** натисне `/start` або `/admin` у боті, бот автоматично розпізнає його нікнейм, відкриє йому **Адмін-панель** та запам'ятає його числовий ID для надсилання сповіщень про нових учасників.
3. **Максимальний захист:** Права адміністратора має **виключно один користувач** (`@wwtivan` / `ADMIN_ID`). Якщо будь-яка стороння людина введе `/admin`, бот **нічого не відповість** (повна тиша).

### Миттєві сповіщення про нових учасників (із прихованим ніком):
Коли новий учасник натискає **«🎉 Участвовать»**, автору миттєво приходить сповіщення:
> 🔔 **Новый участник конкурса!**
> 1. Ім'я Прізвище `<прихований спойлером @username>`

* Нікнейм учасника (`@username`) автоматично прихований під Telegram-спойлером (`<tg-spoiler>@username</tg-spoiler>`), щоб під час запису екрана чи скріншотів особисті контакти не світилися, поки автор сам не натисне на спойлер.
* Якщо у користувача в Telegram **відсутній нікнейм (username)**, бот виводить його ім'я та прізвище, а під спойлером пише `<tg-spoiler>@username</tg-spoiler>` (згідно з вимогою замовника: *«Там где отсутствует ник можно ничего, либо просто @username В скрытом»*).

### Кнопки адмін-панелі (`/admin` або `/start` для адміна):
* **«🏁 Закончить конкурс»** — зупиняє прийом нових заявок (`is_active = False`) і одразу надсилає автору **повний пронумерований список усіх учасників від №1 до останнього**:
  ```text
  🏁 Конкурс завершён! Список всех участников (3):

  1. Олександр <спойлер: @alex_1>
  2. Марія Іванова <спойлер: @username>
  3. Дмитро <спойлер: @dmitry_tg>
  ```
  *(Якщо учасників багато, наприклад 150–1000+, бот автоматично розбиває список на кілька повідомлень, щоб не перевищити ліміт Telegram у 4096 символів).*
* **«📋 Список участников (N)»** — показує поточний список усіх зареєстрованих учасників від 1 до останнього та статус конкурсу без його завершення.
* **«🔄 Новый конкурс (сброс)»** — після підтвердження очищує список учасників поточного конкурсу та знову вмикає прийом заявок з **№1**.
* **«📢 Пост для канала»** — генерує готове посилання `https://t.me/<bot>?start=contest` та шаблон посту з інлайн-кнопкою **«Участвовать»**, який можна переслати або скопіювати для каналу.
* **«🎉 Участвовать (тест)»** — дозволяє автору особисто протестувати реєстрацію в конкурсі.

### Що сказати замовнику при здачі:
1. **Усе працює в одному боті:** Учасники бачать лише кнопку «🎉 Участвовать» і свій порядковий номер, а автор (чий Telegram ID прописаний у `ADMIN_ID` в `.env`) при натисканні `/start` або `/admin` бачить панель керування конкурсом і отримує миттєві сповіщення. Для всіх інших користувачів команда `/admin` повністю невидима (бот на неї не реагує).
2. **Порядкові номери та захист від накрутки:** Кожен учасник отримує строго послідовний номер (`1, 2, 3...`). Повторні натискання одним і тим самим акаунтом блокуються (повертається вже виданий номер).
3. **Приховані нікнейми:** У всіх сповіщеннях та фінальному списку `@username` учасника закритий ефектом спойлера (мерехтливий прихований текст у Telegram). Якщо у людини немає `@username`, вказується її Ім'я/Прізвище та прихований `@username` під спойлером.
4. **Фінальний список для рандомайзера:** Після натискання **«🏁 Закончить конкурс»** бот зупиняє реєстрацію і видає повний список `1..N`, за яким зручно обрати переможця через будь-який генератор випадкових чисел.
